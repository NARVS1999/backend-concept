Migrations & Seeders

Matutunan kung paano gumawa ng model factories at database seeders para sa test data, at paano i-manage ang rollback/refresh strategies.

Lesson Goal Sa lesson na ito, magagawa mong gumawa ng model factories para sa automatic test data generation, mag-setup ng database seeders para sa realistic na data, at ma-rollback ang migrations nang maayos.

Model Factories

Ang model factories ay paraan ng Laravel para mag-generate ng fake data na naka-structure. Sa halip na manually mag-create ng users o posts, gagamitin mo ang factory para auto-generate ang data gamit ang Faker library.

// Gumawa ng factory gamit ang artisan
php artisan make:factory PostFactory --model=Post

// Ang factory file ay nasa database/factories/PostFactory.php
// I-edit ito para i-define ang data structure

// PostFactory.php
class PostFactory extends Factory
{
    protected $model = Post::class;

    public function definition(): array
    {
        return [
            'title' => $this->faker->sentence(6),
            'slug' => $this->faker->unique()->slug(),
            'body' => $this->faker->paragraphs(3, true),
            'status' => $this->faker->randomElement(['draft', 'published', 'archived']),
            'user_id' => User::factory(), // Auto-create user
            'category_id' => Category::factory(),
            'published_at' => $this->faker->optional(0.8)->dateTimeThisYear(),
        ];
    }

    // State: para sa specific scenarios
    public function published(): static
    {
        return $this->state(fn (array $attributes) => [
            'status' => 'published',
            'published_at' => now(),
        ]);
    }

    public function draft(): static
    {
        return $this->state(fn (array $attributes) => [
            'status' => 'draft',
            'published_at' => null,
        ]);
    }
}

// Gumamit ng factory
$post = Post::factory()->create(); // 1 post
$posts = Post::factory()->count(10)->create(); // 10 posts
$published = Post::factory()->published()->create(); // 1 published post
$drafts = Post::factory()->draft()->count(5)->create(); // 5 draft posts

Factory relationships:

// I-define ang relationships sa factory
class PostFactory extends Factory
{
    public function definition(): array
    {
        return [
            'title' => $this->faker->sentence(),
            'body' => $this->faker->paragraph(),
            'user_id' => User::factory(),
            'category_id' => Category::factory(),
        ];
    }

    // Para sa hasMany relationships
    public function withComments(int $count = 3): static
    {
        return $this->afterCreating(function (Post $post) use ($count) {
            Comment::factory()
                ->count($count)
                ->for($post)
                ->create();
        });
    }
}

// Gumamit
$post = Post::factory()->withComments(5)->create();
// Auto-creates 5 comments for the post

Database Seeders

Ang seeders ay classes na nag-populate ng database ng initial data. Ginagamit ito para mag-setup ng test data, default roles, o demo data.

// Gumawa ng seeder gamit ang artisan
php artisan make:seeder PostsTableSeeder

// PostsTableSeeder.php
class PostsTableSeeder extends Seeder
{
    public function run(): void
    {
        // Gumawa ng 50 posts gamit ang factory
        Post::factory()
            ->count(50)
            ->published()
            ->create();
    }
}

// DatabaseSeeder.php — i-collate ang lahat ng seeders
class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        // I-seed ang users muna
        $this->call([
            UsersTableSeeder::class,
            RolesTableSeeder::class,
            CategoriesTableSeeder::class,
        ]);

        // Saka ang posts
        $this->call([
            PostsTableSeeder::class,
        ]);
    }
}

// Run ang seeders
php artisan db:seed
php artisan db:seed --class=PostsTableSeeder
php artisan migrate:fresh --seed // Reset + seed

Realistic data patterns:

// Gumawa ng realistic na data gamit ang Faker + factory
class UserFactory extends Factory
{
    protected $model = User::class;

    public function definition(): array
    {
        return [
            'name' => $this->faker->name(),
            'email' => $this->faker->unique()->safeEmail(),
            'password' => Hash::make('password'), // Default password
            'email_verified_at' => now(),
            'avatar' => $this->faker->imageUrl(200, 200, 'people'),
            'bio' => $this->faker->paragraph(),
        ];
    }

    public function unverified(): static
    {
        return $this->state(fn (array $attributes) => [
            'email_verified_at' => null,
        ]);
    }
}

// Para sa may existing data
class UsersTableSeeder extends Seeder
{
    public function run(): void
    {
        // Gumawa ng admin user
        User::create([
            'name' => 'Admin',
            'email' => 'admin@example.com',
            'password' => Hash::make('password'),
            'email_verified_at' => now(),
        ]);

        // Gumawa ng 10 regular users
        User::factory()
            ->count(10)
            ->create()
            ->each(function ($user) {
                // Auto-create 3 posts sa bawat user
                Post::factory()
                    ->count(3)
                    ->for($user)
                    ->published()
                    ->create();
            });
    }
}

Refresh & Rollback Strategies

Ang migrate:fresh ay nag-d-drop ng buong database at nag-re-run ng lahat ng migrations — ang pinaka-common na ginagamit during development.

// Fresh start — drop lahat, i-run ulit, i-seed
php artisan migrate:fresh --seed

// Rollback ang last migration batch
php artisan migrate:rollback

// Rollback ang last 5 batches
php artisan migrate:rollback --step=5

// Rollback lahat
php artisan migrate:reset

// Status check — ano ang status ng lahat ng migrations
php artisan migrate:status

Rollback strategy para sa production:

// Para sa production, gamitin ang step-by-step approach:

// 1. I-backup ang database muna!
mysqldump -u root -p my_database > backup_$(date +%Y%m%d).sql

// 2. I-run ang migration (hindi fresh!)
php artisan migrate

// 3. I-check kung tama ang result
php artisan migrate:status

// 4. Kung may problema, i-rollback
php artisan migrate:rollback

// 5. Kung okay, i-commit ang code

// SAFETY RULES:
// - HINDI gumamit ng migrate:fresh sa production!
// - LAGING mag-backup bago mag-migrate
// - I-test muna sa staging environment
// - Gumawa ng reversible migrations (may down() method)
// Ang down() method ay para sa rollback
Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained();
    $table->string('title');
    $table->text('body')->nullable();
    $table->timestamps();
});

// Ito ay auto-generated ng artisan — i-check ang down() method
public function down(): void
{
    Schema::dropIfExists('posts');
}

// Para sa columns, gumawa ng separate migration
Schema::table('posts', function (Blueprint $table) {
    $table->string('slug')->after('title');
});

// Down method:
public function down(): void
{
    Schema::table('posts', function (Blueprint $table) {
        $table->dropColumn('slug');
    });
}

Practical: Core Models Factories & Seeders

Gamitin natin ang mga natutunan para gumawa ng factories at seeders para sa isang typical blog app:

// Step 1: Gumawa ng factories
php artisan make:factory UserFactory
php artisan make:factory PostFactory --model=Post
php artisan make:factory CommentFactory --model=Comment
php artisan make:factory CategoryFactory --model=Category

// Step 2: I-define ang factories (tignan sa itaas ang examples)

// Step 3: Gumawa ng seeder
php artisan make:seeder DatabaseSeeder

// Step 4: I-configure ang DatabaseSeeder
class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        // Create admin
        User::create([
            'name' => 'Admin',
            'email' => 'admin@example.com',
            'password' => Hash::make('password'),
        ]);

        // Create categories
        $categories = Category::factory()->count(5)->create();

        // Create users with posts and comments
        User::factory()
            ->count(10)
            ->create()
            ->each(function ($user) use ($categories) {
                Post::factory()
                    ->count(rand(2, 5))
                    ->for($user)
                    ->for($categories->random())
                    ->published()
                    ->create()
                    ->each(function ($post) {
                        Comment::factory()
                            ->count(rand(0, 10))
                            ->for($post)
                            ->for(User::factory()->create())
                            ->create();
                    });
            });
    }
}

// Step 5: Run
php artisan migrate:fresh --seed

Faker methods na madalas ginagamit:

  • $faker->name() — Random name.
  • $faker->safeEmail() — Unique email.
  • $faker->sentence() — Random sentence.
  • $faker->paragraph() — Random paragraph.
  • $faker->imageUrl() — Random image URL.
  • $faker->dateTimeThisYear() — Random date this year.
  • $faker->randomElement(['a','b','c']) — Random from array.
  • $faker->numberBetween(1, 100) — Random number.
  • $faker->optional(0.8)->sentence() — 80% chance na may value, 20% null.

Quiz

Summary

  • Ang model factories ay paraan ng Laravel para mag-generate ng fake data gamit ang Faker — i-define ang data structure at gamitin sa tests at seeders.
  • Ang database seeders ay classes na nag-populate ng database ng initial data — gamitin para sa test data, default records, at demo data.
  • Ang migrate:fresh ay para sa development lang — nag-d-drop at nag-re-run ng lahat. Sa production, gumamit ng migrate at migrate:rollback.
  • Laging mag-backup bago mag-migrate sa production at i-test muna sa staging.
Interview Angle "How do you create test data for a Laravel application?" — Gumagamit ako ng model factories at database seeders. Ang factories ay naka-define sa database/factories/ at nag-generate ng fake data gamit ang Faker. Ang seeders ay nag-populate ng database gamit ang factories. I-run gamit ang migrate:fresh --seed.
