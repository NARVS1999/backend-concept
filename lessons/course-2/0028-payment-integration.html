Payment Integration

Paano mo i-integrate ang payments sa Laravel app mo? Gumamit ng Stripe at PayMongo para sa real transactions.

Lesson Goal Sa lesson na ito, magagawa mong i-integrate ang Stripe at PayMongo payment gateway sa Laravel app, i-handle ang webhooks, i-design ang payment flow, at i-consider ang security best practices para sa payments.

Payment Gateway Options

Kapag nagbubuo ka ng app na may monetization (subscriptions, one-time payments, e-commerce), kailangan mo ng payment gateway. Ito ang service na nagpo-process ng credit card payments at nagta-transfer ng pera sa bank account mo.

Popular na payment gateways:

  • Stripe — Ang pinaka-popular na developer-friendly na gateway. May excellent na API docs, Laravel integration (Cashier), at support sa maraming currencies. Ang transaction fee ay 2.9% + 30 cents per transaction.
  • PayMongo — Ang pinaka-popular na payment gateway sa Philippines. May GCash, Maya (PayMaya), BPI, BDO, at credit/debit card support. Ang transaction fee ay 3.5% per transaction.
  • PayPal — Kilala sa buong mundo pero mas mataas ang fees (4.4% + fixed fee). Madaling i-integrate pero hindi optimal para sa PH-based na apps.
  • Xendit —东南亚 na payment gateway na may support sa PH. May GCash at bank transfer support.

Panatilihin ang Stripe at PayMongo — Ang Stripe ay para sa international payments at mas mura ang fees. Ang PayMongo ay para sa local PH payments (GCash, Maya). Sa Laravel, may Cashier package para sa Stripe na nagbibigay ng ready-to-use subscription at invoice management.

Stripe Integration sa Laravel

Ang Laravel Cashier ay official package para sa Stripe integration. Nagbibigay ito ng clean abstraction over Stripe's API — subscriptions, invoices, payment methods, at customer management.

Creating a checkout session (one-time payment):

// app/Http/Controllers/PaymentController.php
use Stripe\Checkout\Session;
use Stripe\Exception\ApiErrorException;

class PaymentController extends Controller
{
    public function checkout(Request $request)
    {
        $user = auth()->user();

        $session = Session::create([
            'payment_method_types' => ['card'],
            'customer_email' => $user->email,
            'line_items' => [[
                'price_data' => [
                    'currency' => 'usd',
                    'product_data' => [
                        'name' => 'Premium Plan',
                        'description' => 'Monthly access to premium features',
                    ],
                    'unit_amount' => 1999, // $19.99 in cents
                ],
                'quantity' => 1,
            ]],
            'mode' => 'payment',
            'success_url' => route('payment.success') . '?session_id={CHECKOUT_SESSION_ID}',
            'cancel_url' => route('payment.cancel'),
            'metadata' => [
                'user_id' => $user->id,
                'plan' => 'premium',
            ],
        ]);

        return response()->json(['url' => $session->url]);
    }

    public function success()
    {
        return redirect('/dashboard')->with('success', 'Payment successful!');
    }

    public function cancel()
    {
        return redirect('/pricing')->with('error', 'Payment was cancelled.');
    }
}

class SubscriptionController extends Controller
{
    public function subscribe(Request $request)
    {
        $user = auth()->user();

        // I-create ang subscription
        $subscription = $user->newSubscription(
            'default', // subscription name
            'price_monthly_premium' // Stripe Price ID
        )->create($request->paymentMethod);

        return response()->json([
            'message' => 'Subscription created successfully',
            'subscription' => $subscription,

    }

    public function cancel()
    {
        $user = auth()->user();
        $user->subscription('default')->cancel();

        return response()->json(['message' => 'Subscription cancelled']);
    }
}

PayMongo Integration

Para sa Philippine-based na payments (GCash, Maya), ang PayMongo ang pinaka-practical choice. Walang official Laravel package kaya manual integration — pero straightforward naman.

Setup:

# I-add ang PayMongo keys sa .env
PAYMONGO_SECRET_KEY=sk_test_xxxxx
PAYMONGO_PUBLIC_KEY=pk_test_xxxxx

PayMongo service class:

// app/Services/PayMongoService.php
namespace App\Services;

use Illuminate\Support\Facades\Http;

class PayMongoService
{
    protected $secretKey;

    public function __construct()
    {
        $this->secretKey = config('services.paymongo.secret_key');
    }

    public function createSource(float $amount, string $currency, string $type): array
    {
        $response = Http::withBasicAuth($this->secretKey, '')
            ->post('https://api.paymongo.com/v1/sources', [
                'data' => [
                    'attributes' => [
                        'amount' => $amount * 100, // PayMongo uses centavos
                        'currency' => $currency,
                        'type' => $type, // gcash, grab_pay, paymaya
                    ],
                ],
            ]);

        return $response->json()['data'];
    }

    public function createPayment(string $sourceId, float $amount): array
    {
        $response = Http::withBasicAuth($this->secretKey, '')
            ->post('https://api.paymongo.com/v1/payments', [
                'data' => [
                    'attributes' => [
                        'amount' => $amount * 100,
                        'currency' => 'PHP',
                        'source' => [
                            'id' => $sourceId,
                            'type' => 'source',
                        ],
                    ],
                ],
            ]);

        return $response->json()['data'];
    }
}

Controller para sa PayMongo:

// app/Http/Controllers/PayMongoController.php
class PayMongoController extends Controller
{
    public function createPayment(Request $request, PayMongoService $paymongo)
    {
        $validated = $request->validate([
            'amount' => 'required|numeric|min:1',
            'payment_method' => 'required|in:gcash,paymaya,grab_pay',
        ]);

        $source = $paymongo->createSource(
            $validated['amount'],
            'PHP',
            $validated['payment_method']
        );

        // Redirect user sa PayMongo checkout page
        return response()->json([
            'checkout_url' => $source['attributes']['redirect']['checkout_url'],
            'source_id' => $source['id'],
        ]);
    }
}

Webhook Handling

Ang webhooks ay ang paraan kung paano nagno-notify ang payment gateway sa app mo kapag may nangyaring event (payment successful, subscription cancelled, refund processed). Hindi pwedeng mag-rely sa redirect lang — kailangan mo ng webhook para sa reliable payment confirmation.

Stripe webhook handler sa Laravel:

// routes/web.php
Route::post('/webhook/stripe', [WebhookController::class, 'handleWebhook'])
    ->name('webhook.stripe');

// app/Http/Controllers/WebhookController.php
use Laravel\Cashier\Http\Controllers\WebhookController as CashierController;

class WebhookController extends CashierController
{
    protected function handleCheckoutSessionCompleted(array $payload): void
    {
        $sessionId = $payload['data']['object']['id'];
        $userId = $payload['data']['object']['metadata']['user_id'];

        $user = User::findOrFail($userId);
        $user->update(['purchased' => true]);

        Log::info('Payment completed', [
            'user_id' => $user->id,
            'session_id' => $sessionId,
        ]);
    }

    protected function handleInvoicePaymentFailed(array $payload): void
    {
        $customerId = $payload['data']['object']['customer'];

        // I-notify ang user tungkol sa failed payment
        $user = User::where('stripe_id', $customerId)->first();
        if ($user) {
            $user->notify(new PaymentFailedNotification());
        }
    }
}

PayMongo webhook handler:

// app/Http/Controllers/PayMongoWebhookController.php
class PayMongoWebhookController extends Controller
{
    public function handle(Request $request)
    {
        $payload = $request->all();
        $eventType = $payload['data']['attributes']['type'];

        switch ($eventType) {
            case 'source.chargeable':
                $this->handleSourceChargeable($payload);
                break;

            case 'payment.paid':
                $this->handlePaymentPaid($payload);
                break;

            case 'payment.failed':
                $this->handlePaymentFailed($payload);
                break;
        }

        return response()->json(['status' => 'ok']);
    }

    protected function handlePaymentPaid(array $payload): void
    {
        $sourceId = $payload['data']['attributes']['data']['id'];
        $order = Order::where('paymongo_source_id', $sourceId)->first();

        if ($order) {
            $order->update(['status' => 'paid']);
            // I-fulfill ang order (send product, activate subscription, etc.)
        }
    }
}

Webhook security: Mag-verify laging ang webhook signature para hindi ma-spoof ang events. Ang Stripe ay nagbibigay ng signing secret — i-verify ang signature bago i-process ang payload. Ang PayMongo ay nagbibigay ng webhook secret sa dashboard.

Security Considerations

Ang payments ay sensitive na data — kailangan mong sundin ang security best practices:

  • Huwag i-store ang card details — Gumamit ng tokenization (Stripe/PayMongo ang nag-store ng card data). Hindi mo kailangang i-handle ang actual card numbers.
  • Use HTTPS — Lahat ng payment endpoints ay dapat naka-HTTPS. Ito ay requirement ng Stripe at PayMongo.
  • Verify webhook signatures — I-verify ang webhook signature para maiwasan ang spoofed requests.
  • Server-side validation — Huwag mag-rely sa client-side validation lang. I-validate ang payment amount, currency, at status sa server.
  • Idempotency — Gumamit ng unique IDs sa bawat transaction para maiwasan ang duplicate charges. Ang Stripe ay may built-in na idempotency keys.
  • Environment variables — Hindi kailangang i-commit ang API keys sa git. I-store sa .env at huwag i-expose sa client-side code.
