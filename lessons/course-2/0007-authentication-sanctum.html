Authentication with Sanctum

Matutunan kung paano i-setup ang Laravel Sanctum para sa SPA at token-based authentication, at kung kailan gamitin ang Sanctum kaysa Passport.

Lesson Goal Sa lesson na ito, magagawa mong i-setup ang Sanctum auth, gumawa ng login/register endpoints, at i-test ang authentication flow gamit ang frontend.

Ano ang Laravel Sanctum?

Ang Sanctum ay Laravel's lightweight authentication package. Ito ay nagpo-provide ng dalawang authentication methods:

  • SPA Authentication — Cookie-based authentication para sa same-domain frontend (Laravel + Next.js sa iisang domain).
  • Token Authentication — Bearer token authentication para sa mobile apps, third-party API consumers, o ibang domains.

Sanctum vs Passport:

  • Sanctum — Lightweight, para sa first-party SPA/mobile apps. Hindi nagpo-provide ng OAuth2 flows.
  • Passport — Full-featured OAuth2 server. Para sa third-party API access, may complex authorization flows.
  • Para sa ating Roxy project (Laravel API + Next.js frontend), Sanctum ang tamang choice — first-party app lang naman.
// Installation
composer require laravel/sanctum

// Publish config (optional)
php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"

// Run migrations

SPA Authentication Setup

Para sa SPA authentication, kailangan mong i-configure ang Laravel at Next.js na magkaka-domain. Sa development, ito ang setup:

// 1. Add Sanctum middleware to api routes
// routes/api.php
Route::post('/register', [AuthController::class, 'register']);
Route::post('/login', [AuthController::class, 'login']);

Route::middleware('auth:sanctum')->group(function () {
    Route::get('/user', function (Request $request) {
        return $request->user();
    });
    Route::post('/logout', [AuthController::class, 'logout']);
});

// 2. AuthController.php
class AuthController extends Controller
{
    public function register(RegisterRequest $request)
    {
        $user = User::create([
            'name' => $request->name,
            'email' => $request->email,
            'password' => Hash::make($request->password),
        ]);

        $token = $user->createToken('auth-token')->plainTextToken;

        return response()->json([
            'user' => $user,
            'token' => $token,
        ]);
    }

    public function login(LoginRequest $request)
    {
        if (!Auth::attempt($request->only('email', 'password'))) {
            return response()->json([
                'message' => 'Invalid credentials',
            ], 401);
        }

        $user = User::where('email', $request->email)->first();
        $token = $user->createToken('auth-token')->plainTextToken;

        return response()->json([
            'user' => $user,
            'token' => $token,
        ]);
    }

    public function logout(Request $request)
    {
        $request->user()->currentAccessToken()->delete();
        return response()->noContent();
    }
}

Token Authentication for API

Para sa token-based authentication (mobile apps o third-party consumers), ganito ang setup:

// 1. User model - use HasApiTokens trait
use Laravel\Sanctum\HasApiTokens;

class User extends Authenticatable
{
    use HasApiTokens, HasFactory, Notifiable;
}

// 2. Create token during login
$token = $user->createToken(
    'app-name', 
    ['read', 'write'] // abilities
)->plainTextToken;

// 3. Protect routes with abilities
Route::middleware('auth:sanctum:api')->group(function () {
    Route::get('/posts', [PostController::class, 'index'])
        ->middleware('ability:read');
    
    Route::post('/posts', [PostController::class, 'store'])
        ->middleware('ability:write');
});

// 4. Check abilities in controller
public function store(Request $request)
{
    if (!$request->user()->tokenCan('write')) {
        abort(403, 'Unauthorized');
    }
    // ...
}

Token Management:

  • $user->createToken('name') — Gumawa ng bagong token.
  • $user->tokens — I-return ang lahat ng tokens ng user.
  • $user->currentAccessToken() — I-return ang current token.
  • $user->delete() — I-delete ang user at ang lahat ng tokens.
  • $user->revokeAccessTo($appName) — I-revoke ang specific token.

Practical: Auth Flow with Next.js Frontend

Gamitin natin ang Sanctum sa ating Laravel + Next.js setup:

// Laravel side - config/cors.php
'paths' => ['api/*', 'sanctum/csrf-cookie'],
'supports_credentials' => true,

// Next.js side - lib/axios.js
import axios from 'axios';

const api = axios.create({
  baseURL: process.env.NEXT_PUBLIC_API_URL,
  withCredentials: true,
});

// Intercept requests to add token
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// pages/login.js
const handleSubmit = async (data) => {
  try {
    const response = await api.post('/login', data);
    localStorage.setItem('token', response.data.token);
    router.push('/dashboard');
  } catch (error) {
    console.error('Login failed:', error.response.data.message);
  }
};

CSRF Protection:

  • Para sa SPA auth, kailangan mong i-visit ang /sanctum/csrf-cookie endpoint bago mag-login.
  • Ito ay naglo-load ng CSRF token para sa cookie-based authentication.
  • Ang Sanctum middleware ay auto-handle ng CSRF verification.
// Sa Next.js, i-visit ang CSRF endpoint bago mag-login
await api.get('/sanctum/csrf-cookie');
await api.post('/login', { email, password });

Quiz

Summary

  • Ang Sanctum ay lightweight authentication package ng Laravel — para sa SPA (cookie-based) at token-based authentication.
  • Ang SPA authentication ay gumagamit ng cookies at CSRF protection — para sa same-domain frontend.
  • Ang token authentication ay gumagamit ng Bearer tokens — para sa mobile apps o third-party API consumers.
  • Para sa Roxy project, Sanctum ang tamang choice kaysa Passport — first-party app lang naman.
Interview Angle "Explain the difference between Sanctum and Passport." — Ang Sanctum ay lightweight at para sa first-party SPA/mobile apps (cookie o token auth), habang ang Passport ay full OAuth2 server para sa third-party API access. Para sa ating project, Sanctum ang gamit kasi first-party app lang.
