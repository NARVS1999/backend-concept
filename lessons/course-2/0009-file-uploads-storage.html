File Uploads & Storage

Matutunan kung paano i-handle ang file uploads gamit ang Laravel filesystem, i-configure ang local at cloud storage, at mag-implement ng image handling with validation.

Lesson Goal Sa lesson na ito, magagawa mong i-implement ang isang file upload endpoint na may tamang validation, storage configuration, at image processing.

Laravel Filesystem

Ang Laravel filesystem ay nagpo-provide ng unified API para sa file operations. Ito ay nagpo-support ng iba't ibang storage drivers:

  • local — Local filesystem (storage/app directory).
  • s3 — Amazon S3 compatible storage (S3, DigitalOcean Spaces, MinIO).
  • ftp — FTP server.
  • sftp — SFTP server.
// Basic file operations
use Illuminate\Support\Facades\Storage;

// Store file
$path = Storage::disk('local')->put('avatars', $request->file('avatar'));

// Store with custom name
$path = Storage::putFile('avatars', $request->file('avatar'), 'unique-name.jpg');

// Store publicly
$path = Storage::putFileAs('public/avatars', $request->file('avatar'), 'user-1.jpg');

// Read file
$contents = Storage::get('file.txt');

// Delete file
Storage::delete('file.txt');

// Check if file exists
if (Storage::exists('file.txt')) { ... }

// Get file size
$size = Storage::size('file.txt');

// Get last modified
$time = Storage::lastModified('file.txt');

Storage Configuration

I-configure ang storage disks sa config/filesystems.php:

// config/filesystems.php
'disks' => [
    'local' => [
        'driver' => 'local',
        'root' => storage_path('app/private'),
        'serve' => true,
        'throw' => false,
    ],

    'public' => [
        'driver' => 'local',
        'root' => storage_path('app/public'),
        'url' => env('APP_URL').'/storage',
        'visibility' => 'public',
        'throw' => false,
    ],

    's3' => [
        'driver' => 's3',
        'key' => env('AWS_ACCESS_KEY_ID'),
        'secret' => env('AWS_SECRET_ACCESS_KEY'),
        'region' => env('AWS_DEFAULT_REGION'),
        'bucket' => env('AWS_BUCKET'),
        'url' => env('AWS_URL'),
        'endpoint' => env('AWS_ENDPOINT'),
        'use_path_style_endpoint' => env('AWS_USE_PATH_STYLE_ENDPOINT', false),
        'throw' => false,
    ],
],

// Default disk
'default' => env('FILESYSTEM_DISK', 'local'),

Public vs Private Storage:

  • public — Accessible via web. I-link ang storage: php artisan storage:link.
  • private — Hindi accessible via web. Kailangan ng signed URL o response streaming.
  • s3 — Cloud storage. Mas scalable at reliable kaysa local.

File Upload Validation

Palaging i-validate ang file uploads para sa security at data integrity:

// Form Request for file upload
class UploadAvatarRequest extends FormRequest
{
    public function rules()
    {
        return [
            'avatar' => [
                'required',
                'file',
                'image', // MIME type check
                'max:2048', // 2MB max
                'dimensions:max_width=2000,max_height=2000', // Image dimensions
            ],
            'document' => [
                'nullable',
                'file',
                'mimes:pdf,doc,docx', // Allowed extensions
                'max:10240', // 10MB max
            ],
        ];
    }

    public function messages()
    {
        return [
            'avatar.required' => 'Ang avatar ay required.',
            'avatar.image' => 'Ang avatar ay dapat image file.',
            'avatar.max' => 'Ang avatar ay hindi dapat lumagpas sa 2MB.',
            'document.mimes' => 'Ang document ay dapat PDF o Word document.',
        ];
    }
}

Common Validation Rules:

  • file — Valid file upload.
  • image — MIME type: jpeg, png, bmp, gif, svg, webp.
  • mimes:jpg,png,pdf — Specific file extensions.
  • max:2048 — Maximum file size in kilobytes.
  • dimensions:max_width=1920,max_height=1080 — Image dimensions.

Practical: Image Upload Endpoint

Gumawa ng complete image upload endpoint:

// Step 1: Create Form Request
php artisan make:request UploadAvatarRequest

// Step 2: Create Controller Method
class UserController extends Controller
{
    public function updateAvatar(UploadAvatarRequest $request)
    {
        $user = auth()->user();
        
        // Delete old avatar if exists
        if ($user->avatar) {
            Storage::disk('public')->delete('avatars/' . $user->avatar);
        }
        
        // Store new avatar
        $file = $request->file('avatar');
        $filename = time() . '_' . $user->id . '.' . $file->getClientOriginalExtension();
        
        $path = $file->storeAs('avatars', $filename, 'public');
        
        // Update user record
        $user->update(['avatar' => $filename]);
        
        return response()->json([
            'message' => 'Avatar uploaded successfully',
            'avatar_url' => Storage::disk('public')->url('avatars/' . $filename),
        ]);
    }
}

// Step 3: Define Route
Route::middleware('auth:sanctum')->group(function () {
    Route::post('/user/avatar', [UserController::class, 'updateAvatar']);
});

// Step 4: Test
// POST /api/user/avatar
// FormData: { avatar: [file] }
// Response: { message: "Avatar uploaded successfully", avatar_url: "..." }

Quiz

Summary

  • Ang Laravel filesystem ay nagpo-provide ng unified API para sa file operations — supports local, S3, FTP, SFTP.
  • Ang public storage ay accessible via web (kailangan ng storage:link), habang ang private ay kailangan ng signed URL.
  • Palaging i-validate ang file uploads gamit ang image, mimes, max, at dimensions rules.
  • I-store ang files gamit ang Storage::putFileAs() para sa custom filenames at organization.
Interview Angle "How do you handle file uploads in Laravel?" — Gumagamit ako ng Laravel filesystem na may tamang validation (image, mimes, max rules). I-store ang files sa public o private disk depende sa use case, at gumagamit ng Intervention Image para sa image processing kapag kailangan.
