Phase 5: Deployment & Production Readiness — Lesson 1 of 4

Hosting Options

Saan ba ilalagay ang Laravel at Next.js app mo sa production? Paghahambing ng managed hosting vs VPS at alin ang tamang piliin para sa side project.

Lesson Goal Sa lesson na ito, malalaman mo ang pagkakaiba ng managed hosting (Forge, Vapor, Vercel) vs self-hosted VPS (DigitalOcean, Hetzner), ang pros at cons ng bawat isa, at makakagawa ng informed decision kung saan ide-deploy ang Roxy project mo.

Managed Hosting: Laravel Forge at Vapor

Kapag ayaw mong mag-manage ng server configuration, ang managed hosting ang pinakamadaling option. Ang Laravel Forge ay isang service na nag-a-automate ng server setup — provisioning ng VPS, installing PHP/Nginx/MySQL, at deploying code gamit ang git push.

Pros ng Forge:

  • Automated server provisioning — hindi mo na kailangan mag-manual na server setup
  • Built-in SSL certificates (Let's Encrypt integration)
  • Queue workers at scheduled tasks na madaling i-configure
  • Database backups at monitoring dashboard
  • Deployments via git — push to deploy workflow

Cons ng Forge:

  • Bayad — starts at $12/month bukod pa ang VPS cost (minimum $5-10/month sa DigitalOcean)
  • Kailangan mo pa ring mag-manage ng VPS server itself — disk space, memory, at security patches
  • Hindi managed ang actual server — Forge ay tool lang para sa automation

Ang Laravel Vapor naman ay serverless deployment sa AWS Lambda. Walang server na binabayaran — bayad lang sa actual na usage (requests, compute time).

Pros ng Vapor:

  • True serverless — auto-scaling, walang server na imamanage
  • Bayad lang sa actual usage — kapag walang traffic, halos walang gastos
  • Built-in queuing gamit SQS, cache gamit ElastiCache
  • Database sa AWS RDS — managed at reliable

Cons ng Vapor:

  • Mahal kapag lumaki ang traffic — AWS Lambda pricing ay complex at mabilis mag-add up
  • Cold start latency — ang first request pagkatapos ng idle time ay medyo mabagal
  • Hindi lahat ng Laravel features ay compatible sa serverless (file storage, queues)
  • Vendor lock-in sa AWS ecosystem

Para sa side project, ang Forge + $5/month DigitalOcean droplet ay sapat na. Ang Vapor ay mas appropriate para sa production apps na may significant traffic.

VPS: DigitalOcean at Hetzner

Ang VPS (Virtual Private Server) ay pinaka-flexible at cost-effective na option. Ikaw ang nag-a-manage ng lahat — OS, web server, database, SSL, backups. Dalawang popular na provider:

DigitalOcean:

  • $5-6/month para sa 1GB RAM, 25GB SSD droplet
  • Madaling i-set up gamit ang tutorials at documentation
  • Managed databases available ($15/month+) — hindi mo na kailangan i-manage ang MySQL
  • App Platform para sa containerized deployment ($12/month+)
  • Good ecosystem: spaces (S3-compatible), load balancers, at monitoring

Hetzner:

  • €4.50/month (~$5) para sa similar specs — mas mura kaysa DigitalOcean
  • European provider — mas mababa ang latency kung ang users ay sa Europe/Asia
  • Cloud API at CLI available pero mas basic ang documentation
  • Hindi ganun ka-mature ang ecosystem kumpara sa DigitalOcean
# DigitalOcean droplet provisioning
# Minimum specs para sa Laravel + MySQL:
- 1 vCPU, 1GB RAM
- 25GB SSD disk
- Ubuntu 22.04 LTS
- Estimated: $6/month

# Optional: Managed Database (mas secure at reliable)
- MySQL 8.0, 1GB RAM
- Automatic backups at point-in-time recovery
- Estimated: $15/month

Para sa side project, ang $6/month droplet ay sapat na. Ang managed database ay optional pero highly recommended para sa production apps — may automatic backups at hindi mo na kailangan i-manage ang MySQL configuration.

Next.js: Vercel vs Self-Hosted

Ang Vercel ay ang default hosting para sa Next.js — sila ang creators ng framework. Ang deployment ay git-based: i-push mo ang code, i-deploy automatically.

Pros ng Vercel:

  • Free tier para sa personal projects — 100GB bandwidth, 1000 build minutes/month
  • Edge functions, ISR (Incremental Static Regeneration), image optimization — built-in
  • Preview deployments sa bawat PR — maganda para sa team review
  • Custom domains, SSL, at analytics — lahat integrated
  • Zero configuration — gumagana agad sa Next.js

Cons ng Vercel:

  • Vendor lock-in — ang deployment config ay Vercel-specific (vercel.json)
  • Bandwidth limits sa paid tiers — $20/month para sa 1TB bandwidth
  • Hindi mo control ang server configuration — limited ang customization

Self-hosted options:

  • next build && next start sa VPS — gumagana pero walang edge optimization
  • Docker container na i-deploy sa kahit anong cloud provider
  • Dokploy (open-source alternative sa Vercel) — self-hosted deployment platform
# Vercel deployment (simplest)
# Step 1: Connect GitHub repo sa Vercel dashboard
# Step 2: Auto-detect Next.js framework
# Step 3: Set environment variables:
DATABASE_URL=postgresql://...
NEXT_PUBLIC_API_URL=https://api.roxy.com

# Step 4: Deploy — automatic ang build at deployment
# Ang output ay isang URL na: roxy.vercel.app

# Self-hosted alternative (sa VPS):
npm run build
npm run start  # runs on port 3000

# Nginx reverse proxy configuration:
server {
    listen 80;
    server_name roxy.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

Para sa side project, ang Vercel free tier ay perfect — walang gastos at may built-in optimization. Ang self-hosted option ay mas appropriate kapag may specific requirements ka na hindi supported ng Vercel.

Cost Comparison at Decision Framework

Narito ang practical comparison para sa typical na side project:

# OPTION A: Budget-Friendly (Recommended for side projects)
# Laravel backend + Next.js frontend
- Laravel: DigitalOcean VPS $6/month
  - 1 vCPU, 1GB RAM, 25GB SSD
  - Nginx + PHP-FPM + MySQL (all in one)
- Next.js: Vercel Free Tier
  - 100GB bandwidth, unlimited deploys
TOTAL: ~$6/month

# OPTION B: More Production-Ready
- Laravel: DigitalOcean Managed Database $15/month
  - Automatic backups, point-in-time recovery
- Laravel app: DigitalOcean Droplet $6/month
- Next.js: Vercel Free Tier
TOTAL: ~$21/month

# OPTION C: Enterprise / High Traffic
- Laravel: AWS EC2 + RDS (via Forge or manual)
  - EC2 t3.small: ~$15/month
  - RDS db.t3.micro: ~$12/month
- Next.js: Vercel Pro $20/month
  - 1TB bandwidth, team collaboration
TOTAL: ~$47/month

Decision factors:

  • Traffic: Side project na <1000 users/day — VPS + Vercel free tier sapat na
  • Budget: $0 budget — Vercel free tier + Railway/Render free tiers
  • Scalability: Expected na lalaki ang traffic — VPS + managed database, ready mag-scale
  • Learning: Gusto mong matuto ng server management — self-hosted VPS
  • Speed of deployment: Gusto mong mag-launch agad — Vercel + Forge

Para sa Roxy project, ang Option A ang recommended: DigitalOcean VPS para sa Laravel backend ($6/month) at Vercel free tier para sa Next.js frontend. Total na $6/month lang at fully functional na ang production setup.

Practical: Deploy Your First Stack

Step 1: Gumawa ng DigitalOcean account at mag-create ng droplet (Ubuntu 22.04, $6/month). I-save ang SSH key para sa secure access.

Step 2: I-connect sa droplet via SSH at i-setup ang server: install Nginx, PHP 8.2, MySQL, at Composer. Gamitin ang official Laravel deployment documentation.

Step 3: I-deploy ang Laravel app: i-clone ang repo, run composer install, setup .env, run migrations, at i-configure ang Nginx server block.

Step 4: I-connect ang Next.js repo sa Vercel: i-connect ang GitHub repository, i-set ang environment variables (NEXT_PUBLIC_API_URL), at i-deploy.

Step 5: I-test ang buong stack: i-access ang Laravel API endpoint at Next.js frontend. Siguraduhing nagko-connect ang frontend sa backend API.

Step 6: I-setup ang SSL certificates: Let's Encrypt sa Laravel Vercel automatic ang SSL. I-configure ang CORS sa Laravel para sa production domain.

Quiz

Summary

  • Ang managed hosting (Forge, Vapor) ay mas convenient pero mas mahal kaysa self-hosted VPS
  • Para sa side projects, ang DigitalOcean VPS ($6/month) + Vercel free tier ay cost-effective at functional
  • Ang Vercel ay perfect para sa Next.js dahil sa free tier, edge functions, at zero configuration
  • Ang self-hosted VPS ay mas flexible pero nangangailangan ng server management knowledge
  • Consider mo ang traffic, budget, at learning goals mo sa pagpili ng hosting option
