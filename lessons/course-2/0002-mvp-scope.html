Define MVP Scope

Matutunan kung paano i-scope ang iyong MVP — kung ano ang isasama, kung ano ang i-cut, at paano maiwasan ang scope creep habang ginagamit ang AI agents.

Lesson Goal Sa lesson na ito, magagawa mong mag-define ng tamang MVP scope para sa iyong project — maximum 5 core features — at i-validate ito gamit ang AI agent.

Bakit Kailangan ng MVP Scope?

Ang MVP (Minimum Viable Product) ay ang pinakamaliit na version ng product na pwede mo nang i-release sa users. Ang problema ng karamihan: gustong gawin lahat agad.

Kapag hindi ka nag-set ng scope, mangyayari ang mga ito:

  • Scope creep — Laging may "dagdag lang" feature, hindi matapos-tapos.
  • Decision fatigue — Ang daming options, hindi alam kung ano uunahin.
  • AI hallucination — Pag malawak ang scope, mas malaki ang chance na mag-imbento ng features ang AI na hindi mo kailangan.
  • Burnout — Walang finish line, kaya nawawalan ng motivation.

Ang solusyon: max 5 core features. Ito ang rule of thumb. Kung hindi mo ma-express ang MVP sa 5 features, masyado pa itong malaki.

Ano ang "Core" Feature?

Ang core feature ay functionality na kailangan para mabuhay ang product. Hindi "nice to have," hindi "later feature" — ito ang dapat meron para magamit ng user ang product.

Test para malaman kung core ba ang feature:

  1. "Kung wala ito, hindi gumagana ang product?" — Kung hindi, hindi core.
  2. "Kung hindi ito gawin, may 80% ba ng users na aalis?" — Kung hindi, hindi core.
  3. "Kaya ko ba itong i-explain sa 1 sentence?" — Kung hindi, masyadong malaki.

Heto ang example para sa isang e-commerce platform:

## MVP Features (5 max)

### Core (must have)
1. User Registration/Login — Para makapag-login ang users
2. Product Listing — Para makita ang mga products
3. Shopping Cart — Para makapag-add at mag-checkout
4. Payment (GCash/PayMaya) — Para makapag-bayad
5. Order Confirmation — Para malaman ng user na na-process na

### NOT in MVP (cut these first)
- Reviews and ratings — Pwede sa v2
- Wishlist — Nice to have
- Admin dashboard — Manual muna
- Notifications — Email muna, push later
- Search/filter — Basic muna, advanced later

Paano Mag-Cut ng Features

Ito ang framework para mag-decide kung i-cut ba ang feature:

The ICE Framework:

  • I = Impact — Gaano kalaki ang impact nito sa users? (1-10)
  • C = Confidence — Gaano ka sigurado na ito ang tama? (1-10)
  • E = Ease — Gaano kadali ito i-implement? (1-10)
## Feature Scoring Example

| Feature           | Impact | Confidence | Ease | Total |
|-------------------|--------|------------|------|-------|
| User Registration | 9      | 10         | 8    | 27    |
| Product Listing   | 9      | 9          | 7    | 25    |
| Shopping Cart     | 8      | 9          | 6    | 23    |
| Payment           | 10     | 8          | 5    | 23    |
| Order Confirm     | 7      | 9          | 8    | 24    |
| Reviews           | 5      | 5          | 4    | 10    |
| Wishlist          | 3      | 4          | 6    | 7     |
| Admin Dashboard   | 6      | 6          | 3    | 11    |

→ Top 5 lang ang MVP. Cut ang rest.

Practical Exercise: Scope Your MVP

Subukan mo ito gamit ang iyong side business o project idea:

## Exercise: MVP Scoping

1. List ALL features na gusto mo (kahit 20+ items)
   
2. I-score gamit ang ICE framework (Impact, Confidence, Ease)
   
3. I-rank mula pinakamataas hanggang pinakamababa
   
4. Kunin ang TOP 5 lang — ito ang iyong MVP
   
5. I-validate gamit ang AI agent:
   "Here are my 5 MVP features: [list]
    Can you review if:
    - These are truly core (not nice-to-have)
    - I'm missing any critical dependency
    - The order of implementation makes sense
    - These can be built in 2-4 weeks"
   
6. I-commit sa scope — write it down, freeze it,
   at huwag mong baguhin hanggang hindi pa tapos ang MVP

Pro tip: Pagkatapos mo i-freeze ang scope, i-paste ang 5 features mo sa AI agent at sabihin: "Create a BMAD PRD for these features only. Do not add anything else." Ito ang paraan para maiwasan ang AI na magdagdag ng features na hindi mo hiningi.

Quiz

Summary

  • Ang MVP ay pinakamaliit na version ng product na pwede nang i-release — max 5 core features lang.
  • Ang ICE Framework (Impact, Confidence, Ease) ang gamitin para mag-rank at mag-cut ng features.
  • Kapag na-freeze na ang scope, wag nang baguhin hanggang hindi pa tapos ang MVP — iwasan ang scope creep.
  • Pwede mong i-validate ang scope gamit ang AI agent para malaman kung may kulang o mali.
Interview Angle "How do you decide what to build first?" — I-use ang ICE framework para i-prioritize. Ang MVP ko ay laging naka-focus sa 5 core features na may pinakamataas na impact at confidence score. Pagkatapos, i-freeze ko ang scope at hindi na nagdadagdag hanggang hindi pa tapos.
