Normalization & Schema Design

Paano i-structure ang database para hindi magulo, maintainable, at scalable.

Lesson Goal Sa lesson na ito, magagawa mong mag-design ng normalized database schema para sa isang real-world application at ma-explain kung bakit ganun ang structure.

Ano ang Normalization?

Ang normalization ay ang process ng pag-oorganize ng data sa database para mabawasan ang redundancy at maiwasan ang anomalies (insert, update, delete).

1NF (First Normal Form)

  • Bawat column ay dapat may atomic values (isang value lang per cell)
  • Walang repeating groups o arrays sa isang column

2NF (Second Normal Form)

  • Dapat nasa 1NF na
  • Lahat ng non-key columns ay dapat fully dependent sa entire primary key (walang partial dependency)

3NF (Third Normal Form)

  • Dapat nasa 2NF na
  • Walang transitive dependency — non-key columns ay hindi dapat dependent sa ibang non-key columns

Kailan Mag-denormalize?

Minsan, kailangan nating i-break ang normalization rules para sa performance. Halimbawa: sa read-heavy systems, pwedeng magdagdag ng redundant data para iwasan ang maraming JOINs.

Remember Normalize for correctness, denormalize for performance — pero sukatin mo muna kung kelangan talaga.

Schema Design: E-commerce Example

Isipin natin ang schema para sa isang e-commerce app:

  • users — id, name, email, created_at
  • products — id, name, price, stock
  • orders — id, user_id (FK), order_date, status
  • order_items — id, order_id (FK), product_id (FK), quantity, price

Pansinin na ang order_items ay ang junction table para sa M:M relationship between orders and products.

Relationships

  • 1:1 — One user has one profile (pwedeng i-merge sa iisang table)
  • 1:M — One user has many orders (FK sa orders table)
  • M:M — Many products in many orders (junction table)

Summary

  • Normalization (1NF, 2NF, 3NF) ay para mabawasan ang redundancy at anomalies
  • Denormalization ay para sa performance — pero dapat naka-measure na kelangan
  • Relationships: 1:1, 1:M, M:M — bawat isa may appropriate table structure
