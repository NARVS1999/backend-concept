Phase 6: Interview Preparation — Lesson 3 of 4

Mock Technical Q&A

Practice ng random technical questions mula sa lahat ng phases — sagot nang walang notes.

Lesson Goal Masanay sumagot ng technical questions nang walang tulong ng notes o AI.

How to Simulate

  1. Sabihin sa AI agent na maging interviewer
  2. Magta-type o magsasalita ng sagot
  3. Review ang sagot pagkatapos
  4. I-identify kung saang concepts ka nahihirapan — i-review ulit

Sample Questions per Phase

PhaseSample Question
Database"Explain the difference between clustered and non-clustered index."
API"How would you design a paginated API for a social media feed?"
Caching"What happens when cache is full? How does Redis handle eviction?"
Scalability"Explain how you would migrate from a single DB to a sharded setup."
Security"How do you prevent CSRF attacks in a REST API?"

Tips for Answering

  • I-structure ang sagot: definition → how it works → tradeoffs → example
  • Kung hindi alam ang exact answer, magsimula sa "Based on my understanding..."
  • Wag mag-panic — pwede mag-hinge ng clarification
  • Gumamit ng examples mula sa actual experience
