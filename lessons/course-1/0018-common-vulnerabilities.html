Phase 5: Security Fundamentals — Lesson 2 of 3

Common Vulnerabilities

Ang mga karaniwang atake na kailangan mong malaman bilang backend developer.

Lesson Goal Matukoy ang SQL injection, XSS, at CSRF — kung paano ito nangyayari at paano maiiwasan.

1. SQL Injection

Nangyayari kapag ang user input ay direktang naco-concatenate sa SQL query:

// VULNERABLE!
$query = "SELECT * FROM users WHERE email = '" . $_POST['email'] . "'";

// Kung i-input ng attacker: ' OR '1'='1
// Magiging: SELECT * FROM users WHERE email = '' OR '1'='1'

Prevention: Gumamit ng prepared statements o ORM na may parameterized queries. Huwag mag-build ng SQL sa pamamagitan ng string concatenation.

2. XSS (Cross-Site Scripting)

Kapag ang attacker ay nakapag-inject ng malicious JavaScript code sa isang webpage na tinitignan ng ibang users.

  • Stored XSS: naka-store sa database ang malicious script
  • Reflected XSS: nasa URL/request ang malicious script
  • Prevention: I-sanitize ang user input bago i-render (HTML encoding)

3. CSRF (Cross-Site Request Forgery)

Kapag ang attacker ay nagpadala ng request mula sa ibang site gamit ang naka-log-in na session ng biktima.

  • Example: mag-click ang user sa isang link na nagti-trigger ng fund transfer
  • Prevention: CSRF tokens, SameSite cookies, re-authentication
