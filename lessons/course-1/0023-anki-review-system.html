Ano ang Spaced Repetition?

Ang spaced repetition ay isang study technique kung saan ang review intervals ay tumataas habang mas naaalala mo ang isang concept. Ang Anki ay ang pinaka-popular na tool para dito.

How to Use the Export

  1. Bawat lesson ay may "Export to Anki" button sa bawat quiz question
  2. May "Export All to Anki CSV" button sa bawat lesson para i-download lahat ng questions ng lesson na yun
  3. Ang master export ay nasa landing page (index.html) — i-download lahat ng questions mula sa buong course

How to Import to Anki

  1. Open Anki desktop app
  2. Click "File" → "Import"
  3. Select the CSV file
  4. Set the import options: Field separator = Comma, Deck = pick or create new
  5. Map fields: Front → Front, Back → Back
  6. Click "Import"

Anki Tips for Interview Prep

  • Every day, mag-review ng at least 10-20 cards
  • Answer out loud — parang nasa actual interview
  • Kung hindi mo masagot, i-mark as "Again" para bumalik ulit
  • Focus on weak areas — kung confident, i-mark as "Easy" para mas matagal bumalik
