Mock System Design Interview

Practice ng system design interview na may time limit at structured feedback.

Lesson Goal Ma-practice ang "design a rate limiter" at "design a chat application" na may time limit (30-45 mins) gamit ang AI agent bilang interviewer.

The Format (30-45 mins)

  1. Clarify Requirements (5 mins) — Ask questions: scale, features, constraints
  2. High-Level Design (10 mins) — Draw main components and data flow
  3. Deep Dive (15 mins) — Pick one component and go into detail
  4. Tradeoffs (5 mins) — What did you compromise and why?

Practice 1: Design a Rate Limiter

Key elements to discuss:

  • Functional reqs: limit requests per user/IP per time window
  • Non-functional: low latency, distributed, configurable
  • Algorithm: Token bucket vs Sliding window
  • Storage: In-memory vs Redis
  • Response: 429 status code with Retry-After header

Practice 2: Design a Chat Application

Key elements to discuss:

  • 1:1 chat, group chat, online status
  • WebSocket vs polling vs Server-Sent Events
  • Message storage and ordering
  • Presence (online/offline) system
  • Push notifications for offline users
