Load Balancing

Paano ipamahagi ang incoming traffic sa maraming servers para walang isa ang ma-overload.

Lesson Goal Maunawaan ang mga common load balancing algorithms at kung paano mag-set up ng multiple app instances na may load balancer.

Ano ang Load Balancer?

Ang load balancer ay nakaupo sa harap ng servers at nagde-distribute ng incoming requests. Parang receptionist na nag-a-assign ng customers sa available na tellers.

Load Balancing Algorithms

1. Round Robin

  • Sunod-sunod na pag-assign ng requests sa servers
  • Simple at predictable
  • Problema: hindi ini-consider ang current load ng server

2. Least Connections

  • I-forward ang request sa server na may pinakakaunting active connections
  • Mas maganda pag uneven ang processing time ng requests
  • Kailangan i-track ng load balancer ang connections

3. IP Hash

  • Gamit ang client IP para i-determine kung saang server pupunta
  • Consistent — same client, same server
  • Useful for session affinity (sticky sessions)

Health Checks

Ang load balancer ay regular na nag-che-check kung alive ang servers. Kung mamatay ang isang server, awtomatikong hihinto ang load balancer sa pagpapadala ng traffic doon.
