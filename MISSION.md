# MISSION

## Course 1: Backend Concepts & System Design (Sylphiette)

### Bakit Ko Ito Pinag-aaralan?

Gusto kong mag-transition mula **Junior** patungong **Mid-Level Backend Developer**. Hindi sapat na "gumagana" lang ang code — kailangan kong maintindihan ang *bakit* sa likod ng bawat architectural decision para makapasa sa technical interviews at makapag-deliver ng production-grade systems.

### Goals

1. **Malaman ang fundamentals** — databases, API design, caching, scalability, security
2. **Makasagot ng interview questions** nang walang hirap, both behavioral at technical
3. **Makapag-design ng systems** — hindi lang mag-code kundi mag-architect
4. **Maging confident** sa pag-explain ng tradeoffs at technical decisions

### Metrics of Success

- Masagot ang lahat ng Interview Angle questions nang walang notes
- Maka-complete ng hands-on tasks per lesson
- Makapasa ng mock system design interview
- Magkaroon ng Anki deck para sa spaced repetition review

## Course 2: Laravel + Next.js + MySQL (Roxy)

### Bakit Ko Ito Pinag-aaralan?

Gusto kong matutong gumawa ng **full-stack side project/business** gamit ang Laravel API + Next.js frontend + MySQL database approach. Ang goal ay makapag-build ng isang production-ready app na pwedeng i-deploy at gamitin ng totoong users.

### Goals

1. **Master the BMAD → GSD workflow** — gumawa ng spec documents bago mag-code
2. **Build a Laravel REST API** — migrations, controllers, Sanctum auth, queues
3. **Build a Next.js frontend** — App Router, server/client components, data fetching
4. **Connect full stack** — CORS, error handling, API contract documentation
5. **Deploy to production** — CI/CD, monitoring, secrets management
6. **Build for business** — payments, analytics, user feedback

### Metrics of Success

- Makapag-setup ng Laravel API project na gumagana
- Makapag-setup ng Next.js frontend na kumokonekta sa API
- Makapag-implement ng Sanctum authentication end-to-end
- Makapag-deploy ng working app sa production
- Maka-integrate ng payment gateway (Stripe/PayMongo)
- Gumawa ng Anki deck para sa spaced repetition review
