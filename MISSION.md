# MISSION: Backend Concepts & System Design

## Bakit Ko Ito Pinag-aaralan?

Gusto kong mag-transition mula **Junior** patungong **Mid-Level Backend Developer**. Hindi sapat na "gumagana" lang ang code — kailangan kong maintindihan ang *bakit* sa likod ng bawat architectural decision para makapasa sa technical interviews at makapag-deliver ng production-grade systems.

## Goals

1. **Malaman ang fundamentals** — databases, API design, caching, scalability, security
2. **Makasagot ng interview questions** nang walang hirap, both behavioral at technical
3. **Makapag-design ng systems** — hindi lang mag-code kundi mag-architect
4. **Maging confident** sa pag-explain ng tradeoffs at technical decisions

## Metrics of Success

- Masagot ang lahat ng Interview Angle questions nang walang notes
- Maka-complete ng hands-on tasks per lesson
- Makapasa ng mock system design interview
- Magkaroon ng Anki deck para sa spaced repetition review
