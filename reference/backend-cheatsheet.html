Backend Concepts — Quick Reference

Cheat sheet para sa Jr → Mid-Level interview prep

Database

Normalization 1NF (atomic), 2NF (no partial dependency), 3NF (no transitive dependency) — iwas redundancy
B-tree Index O(log n) search. Effective para sa = > < BETWEEN. May write overhead.
Composite Index Column order matters — equality columns first. Index ng multiple columns.
N+1 Problem 1 query + N queries per row. Fix: eager loading (JOIN / WHERE IN).
ACID Atomicity, Consistency, Isolation, Durability. Reliable transactions.
Isolation Levels Read Uncommitted → Read Committed → Repeatable Read → Serializable.

API Design

REST Stateless, resource-based, uniform interface. Plural nouns, proper HTTP verbs.
PUT vs PATCH PUT = replace entire resource. PATCH = partial update lang.
Status Codes GET=200, POST=201, DELETE=204, 429=Rate Limited.
Pagination Offset (simple, unstable) vs Cursor (stable, fast, no page jump).
Rate Limiting Token bucket (allows bursts) or Sliding window (accurate). Use Redis for distributed.
Versioning URL (/v1/) or Header (Accept). Deprecate muna, huwag biglang tanggalin.

Caching & Performance

Cache-Aside Check cache → miss → query DB → store in cache → return. Read-heavy workloads.
Write-Through Write to cache + DB simultaneously. Always fresh, pero slower writes.
Cache Invalidation TTL (auto-expire), Event-based (real-time), Cache tagging (batch clear).
Background Jobs Sync blocks user; async uses queues (RabbitMQ, SQS, Redis) for offloading.

Scalability

Vertical Scaling Palakasin ang isang server. Simple pero may upper limit.
Horizontal Scaling Dagdagan ang servers. Unlimited pero need statelessness + load balancer.
Load Balancer Round Robin, Least Connections, IP Hash. Health checks auto-remove dead servers.
Replication Copy DB for read scaling. Writes sa master, reads sa replicas. May replication lag.
Sharding Split DB for write scaling. Key-based, range-based, or directory-based.
CAP Theorem Choose 2 of 3: Consistency, Availability, Partition Tolerance. CP (banking) vs AP (social media).

Security

Authentication vs Authorization Auth = identity verification. Authz = permission checking.
JWT Stateless token. Payload ay naka-encode, hindi naka-encrypt — wag lagyan ng sensitive data.
SQL Injection Prevention: prepared statements / parameterized queries.
Password Hashing Use bcrypt or Argon2. Slow + salt. Huwag gumamit ng MD5/SHA1.

Interview Prep

STAR Method Situation, Task, Action, Result — i-frame ang stories.
System Design Framework Clarify → High-level → Deep Dive → Tradeoffs.
